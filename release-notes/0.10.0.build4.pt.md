# bubo 0.10.0 build 4

Este build corrige o loop da prática: o mesmo card não volta mais quando você
responde e aperta próximo.

## Novidades

- **Próximo é próximo**: depois de responder um card, "Próximo card" nunca mostra o mesmo card de novo. Quando não há mais nada vencido, a sessão termina com "Tudo em dia" em vez de reiniciar a fila.
- **Prática extra explícita**: "Praticar mesmo assim" agora é o único caminho para ver um card de novo, então o fallback automático não entra mais em loop com um único card salvo.
