# bubo 0.8.5

This release is about a calmer screen: fewer things competing for attention, a
settings tab that actually explains an update, and a compact mode that reads
like a conversation.

## What's new

- **Updates tab**: updates moved out of System into their own settings tab. When
  a new version is available, the card now shows the actual changes from the
  release notes instead of the raw Markdown body.
- **Floating learning actions**: new chat, history, progress and practice float
  in a small pill under the bubo title, so the header stays a single row.
- **Appearance in System**: message text size and theme now live in the System
  tab, next to the behavior settings. The settings tabs wrap instead of hiding
  tabs behind a horizontal scroll.
- **Slimmer scrollbars**: a global scrollbar style with a small thumb and a
  wider invisible hit area, plus contained overscroll so the chat does not
  bounce.
- **Compact mode**: your messages sit on the right and bubo on the left, like
  the full chat, and the mascot is larger.
- **Beginner challenge fixed**: bubo no longer asks you to repeat an English
  phrase it just showed you. When you ask how to say something, it still gives
  a hint first and keeps the answer hidden.

## Upgrade

Nothing to do. Settings → Atualizações offers 0.8.5 like any other version.
