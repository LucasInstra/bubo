# bubo 0.9.1 build 7

This build closes the P1 issues from the audit: reading old replies, keeping
deletions honest, the first run, updates outside the chat, and accessibility.

## What's new

- **Saved bilingual replies**: a conversation stored in bilingual mode now
  reads correctly after you change the reply language. The body follows the
  setting, the other language stays behind the reveal, and no raw `EN:` or
  `PT:` line is left in the text.
- **Translation challenge everywhere**: compact and popup now hide the
  Portuguese half of older replies behind the same reveal as the full chat.
- **Deleting**: removing a message or a whole conversation now removes the
  corrections it produced, including their copy on other messages, so a
  deleted card no longer comes back on the next start.
- **First run**: the setup wizard can be dismissed, so history, practice,
  settings and backup stay reachable before a key is connected.
- **Updates**: the setup wizard, compact and popup now announce an available
  build, and a failed install is visible there instead of only in Settings.
- **Accessibility**: new messages are announced, the composer and the practice
  input have stable labels, the practice verdict is read out, and selection
  chips expose their pressed state. Escape while renaming a conversation no
  longer closes the list, and two fast history clicks open the conversation
  you clicked last.
