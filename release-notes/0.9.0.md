# bubo 0.9.0

This release is about the first five minutes: bubo now walks you through the
API key instead of dropping you into a settings form, and a few lesson and
chat details got out of the way.

## What's new

- **First-run onboarding**: before the chat, a setup screen explains what an
  API key is in plain language, with a short tutorial for a free Groq key, a
  field that recognizes an existing Groq, OpenAI or OpenRouter key, and an
  Ollama path that needs no key at all.
- **Lessons accept the whole sentence**: fill-in exercises now accept the
  completed sentence as well as the missing word, so a correct answer is not
  marked wrong just because it includes the rest of the sentence.
- **Practice starts with bubo**: finishing a lesson and choosing "Praticar na
  conversa" opens the chat with a bubo message about that lesson and an
  invitation to practice.
- **English can be hidden again**: after revealing the English in a bilingual
  reply, a "esconder inglês" button puts it back behind the reveal.
- **Portuguese release highlights**: the Updates tab and the update-available
  card now show Portuguese highlights. The English notes remain the GitHub
  release body, and the updater manifest carries both.
- **Beginner chat stays conversational**: bubo no longer asks you to produce
  an English sentence in the chat, so the answer cannot appear inside the
  question. Production lives in the lessons and practice cards.

## Upgrade

Nothing to do. Settings → Atualizações offers 0.9.0 like any other version.
