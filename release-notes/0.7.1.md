# bubo 0.7.1

This release makes bubo usable before you can read English, and gives bilingual
replies a cleaner home in the chat.

## What's new

- **Reply language**: choose English only, English with a short Portuguese translation, or Portuguese only. Existing settings that had the old translation help enabled move to the bilingual option automatically.
- **Portuguese-first mode**: when Portuguese only is selected, the tutor speaks Portuguese, keeps useful English words and phrases in context, and explains their meaning in Portuguese.
- **Readable corrections**: messages written only in Portuguese are not treated as English mistakes. Choosing Portuguese only also starts the correction notes in PT-BR, and you can still switch them to English.
- **Translation blocks**: the bilingual `PT:` line now renders as a separate block in the full chat, compact mode, and the popup instead of running into the English reply.
- **First contact**: the empty state, conversation starters, and composer placeholder follow the Portuguese-only mode.
- **Polish**: refreshed PT-BR screenshots and site copy, a new build label, and a cleaner roadmap.

## Upgrade

Your settings file is migrated on load. Older builds stored translation help as a boolean; `true` becomes the bilingual option, and an absent value becomes English only.
