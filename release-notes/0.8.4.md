# bubo 0.8.4

This release is about moving around the app faster and knowing what a practice
card wants from you before you type.

## What's new

- **Settings tabs**: the settings screen used to be one long scroll. It now has
  five tabs — Learning, Connection, Practice, Appearance and System — with arrow,
  Home and End navigation, and each tab opens at the top.
- **Two-row header**: new chat, history, progress and practice moved to their own
  row under the bubo title. Pin, compact, popup, settings and hide stay on the
  first row.
- **Mascot preview stays put**: in the customization screen the preview is now
  sticky, so the eye and mouth controls can be changed with the mascot still on
  screen instead of scrolling back and forth.
- **Hint before the answer**: a practice card now shows the correction note (for
  example `past simple`) while you type, instead of only after the review. A note
  that already spells out the correction is held back, so the answer stays
  hidden until you commit to one.
- **Message search**: the search button matches the send button again, Escape
  closes the search, and the mascot steps out of the way while it is open.

## Upgrade

Nothing to do. Settings → Updates offers 0.8.4 like any other version.
