# bubo 0.10.0 build 3

This build fixes the conversation rhythm and closes the reliability issues
found in the code review.

## What's new

- **A question in every reply**: bubo now closes almost every answer with one
  concrete question taken from what you just said, so you never have to carry
  the conversation alone. Beginners get questions they can answer in a few
  words, and the same question is never repeated.
- **No English echo**: after a message written in English, bubo no longer
  invites you to say the same thing in English, and never hands your own
  sentence back as a target.
- **Safer data**: an unreadable database is moved aside and the app opens with
  a notice instead of dying silently; a broken settings field no longer resets
  every preference, and saving is atomic.
- **Deleting stays deleted**: corrections are never saved for a conversation
  you already removed, and a message that is not saved yet can no longer be
  deleted from the screen only.
- **Backup and restore**: backup refuses to overwrite the live database or a
  foreign file, and restore keeps a copy of the previous database for rollback.
- **Stop really stops**: cancelling now interrupts the request itself instead
  of waiting for the next chunk, and the popup has a Stop button too.
- **Nothing typed is lost**: the composer keeps your draft when the popup
  collapses or the app switches between compact and full.
- **Visible feedback**: a failed update install shows the error and a retry in
  the chat, new replies are announced to screen readers, and a recovered
  database is explained on screen.
