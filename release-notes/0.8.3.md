# bubo 0.8.3

A maintenance release that moves the whole toolchain forward. There are no
functional changes: the app should look and behave exactly like 0.8.2 build 2.

## What changed under the hood

- **React 19**: React and React DOM from 18 to 19, with the matching type
  packages. The only code change was the shared modal focus hook, which now
  accepts the nullable ref type React 19 returns from `useRef`.
- **Vite 8**: the build pipeline moved to Rolldown and Oxc. The explicit
  esbuild minifier is gone, so the build now asks for Oxc, the default in this
  version.
- **TypeScript 6.0**: the newest version the lint toolchain accepts.
  `typescript-eslint` still caps TypeScript below 6.1, so 7 is not installable
  yet.
- **rusqlite 0.40**: the database crate, with no API change on our side.
- **GitHub Actions**: checkout, configure-pages, deploy-pages,
  upload-pages-artifact and tauri-action all on their current majors.

## Upgrade

Nothing to do. Settings → Updates offers 0.8.3 like any other version.

## Build

- Version **0.8.3**, build **1**.
- x64 installer signed with the updater key (not Authenticode); SmartScreen may
  warn on first run.
- Update packages are verified with the Tauri updater signing key.

## Verification

- 79 Vitest tests, 78 Rust tests, 34 Playwright tests, clippy, fmt, and build
  clean, locally and in CI.

## Note

The React 19 upgrade grows the frontend bundle from roughly 406 kB to 480 kB
raw (126 to 146 kB gzipped). No startup regression was measured, but the binary
is slightly larger than 0.8.2.
