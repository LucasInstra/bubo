# bubo 0.10.0 build 2

This build closes the rest of the P2 audit list.

## What's new

- **Study focus at every level**: B1/B2 now keep the focus you picked, both in
  the conversation and in corrections, and the field no longer disappears
  above A2.
- **Lesson intro once**: finishing the same lesson twice no longer saves the
  intro twice, so restarting the app does not show the line duplicated.
- **Smaller entry bundle**: the markdown renderer and React ship as separate
  files, so the main chunk dropped from 553 kB to 216 kB and the build warning
  is gone.
