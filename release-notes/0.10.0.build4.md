# bubo 0.10.0 build 4

This build fixes the practice loop: the same card no longer comes back when you
answer it and press next.

## What's new

- **Next means next**: after answering a card, "Próximo card" never shows that
  same card again. When nothing else is due, the session ends with "Tudo em dia"
  instead of cycling the queue from the start.
- **Explicit extra practice**: "Praticar mesmo assim" is now the only way to see
  a card again, so the automatic fallback cannot loop on a single saved card.
