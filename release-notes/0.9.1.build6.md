# bubo 0.9.1 build 6

This build fixes the evaluation and correction issues found in the audit.

## What's new

- **Answer checking**: lessons and practice now compare whole words, so
  `Where do you lives?` no longer passes, while contractions such as `She's`
  and `I'd` are accepted.
- **Lesson cards**: a wrong full sentence now saves the full corrected
  sentence, so the practice card accepts the answer the learner actually
  needs to write.
- **Recurring mistakes**: when the same mistake appears again, the card is due
  immediately instead of staying weeks in the future.
- **Corrections**: Portuguese-only messages are never corrected into English,
  the correction pass looks at the learner's message instead of the
  instruction, and malformed or missing fields are tolerated.
- **Stop**: a new turn keeps its Stop control while the previous turn is
  finishing its corrections.
- **Build notes**: every fix build now has its own public notes, both on the
  release page and in the update card.
