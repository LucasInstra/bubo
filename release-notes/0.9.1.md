# bubo 0.9.1

This release makes fix builds reachable from inside the app and closes the last
chat behavior that could reveal an answer.

## What's new

- **Build updates**: the updater now compares the build number as well as the
  version, so a new build of the same version appears in the update button and
  installs from inside the app. This is the release that turns that on; later
  fix builds arrive without a manual install.
- **Chat stays conversational**: bubo no longer asks for a full English
  sentence in the chat, at any level, so the answer cannot appear inside the
  question. Production lives in the lessons and practice cards.
- **English nudges**: at every level, bubo reacts to what you said and then
  invites you to try one short idea in English, with a starter of one to three
  words, never the full sentence. At A1/A2 the invitation is optional and
  shorter; the complete English version stays in the hidden EN line.
- **Everything from 0.9.0**: first-run onboarding, full-sentence lesson
  answers, the practice intro, hiding the English again, and Portuguese
  release highlights.

## Upgrade

Settings → Atualizações offers 0.9.1 like any other version. This is the last
update that needs a normal version bump; after it, fix builds of 0.9.1 appear
in the same update button.

## Build

- Version **0.9.1**, build **5**.
- x64 installer signed with the updater key (not Authenticode); SmartScreen may
  warn on first run.
- Update packages are verified with the Tauri updater signing key.
