# bubo 0.8.1

This release packages the build 12 and 13 fixes into a normal public version, so
existing installations can update from inside the app.

## What's new

- **User data folder**: the database, settings, logs and window state now live in `%APPDATA%\bubo`. Existing data is migrated on first launch. The bundle identifier stays the same so the installer and updater keep their identity.
- **Feedback**: Settings now has a Feedback card that opens the GitHub issue page.
- **Beginner challenges**: at A1/A2, bubo no longer includes the English answer in the question when asking the learner to produce a sentence. The hint stays a hint.

Builds 12 and 13 of 0.8.0 were published only as the stable `bubo-setup.exe` asset. 0.8.1 brings them to everyone through the updater.

## Upgrade

Existing settings and history are migrated automatically. If the old `%APPDATA%\com.lucas.bubo` folder is still present after the first launch, it is a fallback copy; it can be removed once the new folder has the data.

## Build

- Version **0.8.1**, build **1**.
- x64 installer signed with the updater key (not Authenticode); SmartScreen may warn on first run.
- Update packages are verified with the Tauri updater signing key.

## Verification

- 65 Vitest tests, 78 Rust tests, 34 Playwright tests, clippy, fmt, and build clean.

## Fix build (build 2)

The stable `bubo-setup.exe` was rebuilt with clearer before/after highlights in
the correction cards, the practice result and the progress list. The version
remains 0.8.1, and existing installations are not auto-updated to this build.
