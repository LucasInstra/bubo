# bubo 0.8.6

This release closes the loop on the updates screen and fixes the mascot's face
when the eyes are large.

## What's new

- **Version highlights**: the Updates tab now has a card with what changed in
  the version that is actually running, not only in an update that is waiting.
  The notes ship with the build, so the card works offline and always matches
  the installed version.
- **Mouth below the eyes**: tall eye shapes now grow upward and the mouth sits a
  little lower, so a large eye size never puts the mouth on top of the eyes.

## Upgrade

Nothing to do. Settings → Atualizações offers 0.8.6 like any other version.

## Build

- Version **0.8.6**, build **1**.
- x64 installer signed with the updater key (not Authenticode); SmartScreen may
  warn on first run.
- Update packages are verified with the Tauri updater signing key.

## Verification

- 93 Vitest tests, 78 Rust tests, 35 Playwright tests, clippy, fmt, and build
  clean, locally and in CI. The release card has its own e2e test and the e2e
  harness now reports the real package version.
