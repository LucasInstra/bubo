# bubo 0.7.0

Primeira release com o lote grande de melhorias depois da 0.6.5.

## Novidades

- **Backup e diagnóstico**: exportar/restaurar o banco, abrir a pasta de dados e copiar um relatório de diagnóstico.
- **Histórico**: busca, renomear e arquivar conversas.
- **Prática**: botão “eu estava certo”, meta diária de revisões e lembrete diário.
- **Conversa**: markdown nas respostas, busca na conversa atual e limite de contexto com aviso.
- **Rede**: proxy HTTP(S) e certificado CA personalizado para redes corporativas.
- **Aparência**: tema claro/escuro/sistema e UI em PT-BR.
- **Popup**: posição lembrada entre reinícios e opção de iniciar oculto.
- **Distribuição**: zip portable x64 anexado; build ARM64 disponível pelo workflow manual.

## Build

- Versão **0.7.0**, build **8**.
- Instalador x64 assinado com a chave do updater (não Authenticode); o SmartScreen pode avisar na primeira execução.

## Verificação

- 56 testes Vitest, 55 testes Rust, 23 testes Playwright, clippy, fmt e build limpos.
