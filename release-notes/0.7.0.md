# bubo 0.7.0

First release with the large batch of improvements since 0.6.5.

## What's new

- **Backup and diagnostics**: export or restore the database, open the data folder, and copy a diagnostics report.
- **History**: search, rename, and archive conversations.
- **Practice**: "I was right" button, daily review goal, and daily reminder.
- **Chat**: Markdown in replies, search in the current conversation, and a context limit with a warning.
- **Network**: HTTP(S) proxy and custom CA certificate for corporate networks.
- **Appearance**: light, dark, or system theme, and a PT-BR UI.
- **Popup**: window position remembered across restarts, plus an option to start hidden.
- **Distribution**: portable x64 zip attached; ARM64 build available through the manual workflow.

## Build

- Version **0.7.0**, build **8**.
- x64 installer signed with the updater key (not Authenticode); SmartScreen may warn on first run.

## Verification

- 56 Vitest tests, 55 Rust tests, 23 Playwright tests, clippy, fmt, and build clean.
