# bubo 0.8.2

This release makes fix builds reachable from inside the app. Until now a fix
that reused an existing version shipped only as the stable `bubo-setup.exe`
download, and installations already on that version never heard about it.

## What's new

- **Build-aware updates**: the update manifest now carries a `build` number next to the version. A newer version always wins, and the same version is offered only when its build is higher. Fix builds published with the **Fix build** workflow update existing installations like a normal version.
- **Clearer update card**: when the offer is a build of the version you already have, Settings → Updates names both, for example `A versão 0.8.2 · build 3 está disponível.`

## How it works

`allowDowngrades` is enabled in the updater configuration, because the plugin only offers versions that are strictly newer. bubo compares the announced version and build against the running binary and ignores anything that is not newer, so the flag cannot downgrade you.

## Upgrade

Nothing to do. From 0.8.2 on, fix builds of the same version appear in Settings → Updates. The first updater-enabled release still has to be installed by hand once.

## Build

- Version **0.8.2**, build **1**.
- x64 installer signed with the updater key (not Authenticode); SmartScreen may warn on first run.
- Update packages are verified with the Tauri updater signing key.

## Verification

- 79 Vitest tests, 78 Rust tests, 34 Playwright tests, clippy, fmt, and build clean.

## Fix build (build 2)

This build exists to prove the new path end to end: it was published with the
**Fix build** workflow on the existing 0.8.2 release, without a new version, and
regenerated `latest.json` with `build: 2`. Installations on 0.8.2 build 1 should
see it in Settings → Updates. There are no functional changes beyond build 1.
