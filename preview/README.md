# Reaction lab

`preview/reactions.html` uses the real `Mascot` component and lets you trigger every state and mood with buttons. It needs the Vite dev server:

```powershell
npm run dev
```

Open `http://localhost:1420/preview/reactions.html`. Click the bubo for a boop, drag a cheek for the grab, or use the state and mood buttons. The "show mouth" checkbox reveals the talking, smile and frown animations. The eye selector switches the nine eye styles, which is the quickest way to check the no-mouth expressions: sad switches to the fixed diagonal dashes, surprised scales and lifts the eyes, and streaming pulses them and draws a small audio meter beside the head.
